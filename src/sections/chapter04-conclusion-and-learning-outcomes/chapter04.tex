\section{Conclusion}
The twelve-week internship at Power Gym Budibazar Pokhara provided an immersive, hands-on engineering experience that successfully bridged the academic curriculum of the B.Sc. CSIT program with the demands of production mobile software engineering. Stationed as a Mobile Application Developer Intern within the Digitalization Unit under the mentorship of Mr.~Krishna Subedi, the primary objective was to architect, develop, integrate, and verify a dedicated cross-platform mobile fitness platform---Alcedo---to modernize athletic training management for the gym's growing membership base.

Throughout the internship, the formulated technical milestones were systematically fulfilled across both client and server tiers:
\begin{itemize}
    \item On the client tier, a responsive, accessible mobile application was constructed using React Native 0.86, React 19, and Expo SDK 57 in TypeScript. The frontend incorporates a robust UI design system comprising over 80 reusable foundation components governed by centralized design tokens in \textit{theme.ts}, supporting seamless dynamic theming across Light, Dark, and true-black OLED display modes.
    \item The client navigation architecture organizes twenty-four functional route screens across five primary tabs (Workout, Feed, Stats, History, and Settings) using Expo Router's declarative, file-based routing framework.
    \item To address the connectivity constraints common in fitness facilities, an offline-first data layer was engineered utilizing an embedded SQLite database managed via Drizzle ORM across seventeen relational tables with nine sequential SQL migrations, supplemented by hardware-backed encryption in \textit{Expo SecureStore} for authentication tokens.
    \item Client-side application state was centralized into eleven Redux Toolkit slices coordinated by reactive listener middleware (\textit{addEffect}) for non-blocking local persistence.
    \item On the server tier, modular backend services were developed within a NestJS 11 and MongoDB 8 architecture, implementing User Management profile endpoints (\textit{GET} and \textit{PATCH /api/users/me}), Workout Management CRUD operations and batch synchronization contracts with idempotency keys, and dynamic Feature Management capability flags (\textit{GET /api/features}).
    \item A secure network communication layer was established via the \textit{authenticated-fetch} wrapper, featuring automated JWT bearer token injection and a single-flight 401 refresh interceptor that eliminates racing token refresh requests.
    \item The codebase was systematically verified through multi-layered testing, encompassing 140 Vitest client specifications, generative property tests via Fast-Check, 19 Jest backend suites, and strict TypeScript typechecking gates.
\end{itemize}

The delivery of Project Alcedo represents a significant technological transition for Power Gym Budibazar Pokhara. Previously reliant on physical reception desk ledgers, paper workout notebooks, and static Facebook announcements ($\sim$1.7K followers), the gym now possesses a modern, branded digital software asset capable of guiding members through structured workout routines, logging progressive overload metrics, and providing longitudinal performance analytics. Working under the guidance of company mentor Mr.~Krishna Subedi and coordinating with the Gym Manager, front-desk administrators, and fitness instructors provided invaluable insight into collaborative requirement gathering, translating athletic domain practices into relational database schemas, and balancing software architecture with production constraints.

\section{Learning Outcome}
The internship experience fostered comprehensive professional, technical, and architectural competencies across the full software engineering lifecycle. By actively contributing to both frontend application layers and supporting backend modules, the intern developed strong domain proficiencies that directly reinforce theoretical computer science concepts.

The technical learning outcomes acquired during the internship include:
\begin{itemize}
    \item \textbf{Cross-Platform Mobile Engineering:} Deepened practical mastery of modern React Native (version 0.86), React 19 concurrent features, and the Expo SDK 57 ecosystem. Gained practical experience in native bridge paradigms, Hermes bytecode execution, platform-split component styling, and mobile lifecycle optimization.
    \item \textbf{Declarative Routing and Navigation Architecture:} Acquired proficiency in file-based mobile navigation utilizing Expo Router, understanding how filesystem route hierarchies enforce screen encapsulation, facilitate deep-linking, and manage nested stack and modal transitions across multi-tab applications.
    \item \textbf{Atomic Design Systems and Component Tokenization:} Learned to architect scalable user interfaces by establishing centralized design tokens (typography scales, semantic color palettes, spacing metrics) and building modular, reusable foundation component kits that ensure visual coherence across varying mobile viewports.
    \item \textbf{Reactive State Management and Middleware Side-Effects:} Developed advanced competency in managing client-side application state using Redux Toolkit. Learned to prevent prop-drilling, maintain predictable unidirectional data flow through domain slices, enforce immutable state updates via Immer, and decouple asynchronous persistence side-effects using custom listener middlewares.
    \item \textbf{Offline-First Data Architecture and Embedded Persistence:} Mastered offline-first mobile architecture by implementing an embedded SQLite database with Drizzle ORM. Learned to design normalized relational schemas (17 tables), author sequential SQL migrations, optimize indexed queries for high-frequency workout logging, and secure cryptographic credentials using hardware-backed keychains.
    \item \textbf{Modular Backend Development and RESTful API Design:} Strengthened server-side engineering capabilities using NestJS and MongoDB (Mongoose ODM). Gained practical experience in applying enterprise architectural patterns---such as Inversion of Control (IoC), Dependency Injection (DI), layered Controller-Service-Repository structures, and class-validator DTO validation---to construct maintainable RESTful services.
    \item \textbf{Stateless Token Security and Interceptor Patterns:} Acquired practical understanding of JSON Web Token (RFC 7519) lifecycles. Implemented resilient network interceptors featuring single-flight 401 refresh mutexes to maintain uninterrupted session continuity and prevent concurrent refresh race conditions.
    \item \textbf{Automated Software Verification and Quality Assurance:} Developed disciplined quality assurance habits by writing and maintaining automated unit test suites (Vitest, Jest), component simulation specs, and property-based test suites. Learned to enforce strict static typechecking (zero TypeScript errors) and linter rules as mandatory pre-commit verification gates.
\end{itemize}

Beyond technical proficiencies, the internship provided crucial growth in professional engineering practices, project management, and interpersonal collaboration:
\begin{itemize}
    \item \textbf{Disciplined Version Control and Merge Management:} Developed expertise in professional Git workflows, adopting Conventional Commits with structured commit bodies that explicitly record verification evidence and test tallies. Gained experience in risk mitigation during complex branch merges through documented merge ledgers and hazard registers.
    \item \textbf{Cross-Disciplinary Requirement Elicitation:} Gained experience in communicating with non-technical stakeholders---including gym management, front-desk receptionists, and fitness trainers---to translate athletic exercise workflows and administrative policies into precise software requirements.
    \item \textbf{Time Management and Engineering Prioritization:} Learned to estimate task complexity accurately, sequence interdependent frontend and backend milestones under strict deadlines, and navigate technical tradeoffs within a 12-week delivery timeframe.
    \item \textbf{Constructive Code Review and Feedback Integration:} Developed professional maturity by receiving constructive feedback from the industrial mentor, refining code implementations iteratively, and adhering to strict software maintainability guidelines.
\end{itemize}

Through these responsibilities and learning outcomes, the intern successfully bridged the gap between academic education and professional software engineering. Applying the theoretical foundations of the B.Sc. CSIT curriculum to a live, production-grade mobile application provided comprehensive, hands-on experience across frontend design, backend integration, local embedded persistence, automated testing, and software quality assurance. This engagement has established a solid professional foundation for a future career in mobile software engineering, full-stack application development, and modern information technology.
