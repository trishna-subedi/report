\vspace{0.3in}
This report presents the experience and learning outcomes of a twelve-week internship undertaken as a Mobile Application Developer Intern in the Digitalization Unit of Power Gym Budibazar Pokhara, Pokhara-26, Kaski. The core project was the development of Alcedo, a cross-platform mobile fitness application built with React Native, Expo, and TypeScript, supported by a NestJS and MongoDB backend. The primary responsibility was frontend development and user interface implementation, including reusable components such as buttons, cards, and input fields, screen layouts with consistent text and spacing, and navigation between screens using Expo Router. Client-side state was managed with Redux Toolkit, and offline persistence was handled using SQLite through Drizzle ORM. Backend contributions covered User Management for retrieving and updating user profiles, Workout Management for creating, retrieving, updating, and deleting workout data, and Feature Management using feature flags served through backend configuration. Frontend components were integrated with backend services with loading and error handling, and the implemented screens and functionalities were systematically tested and debugged. The internship bridged classroom learning with professional engineering practice, strengthening skills in mobile application development, backend integration, testing, and teamwork.

\vspace{1.5em}
\noindent\textbf{Keywords:} Mobile Application Development, React Native, Expo, TypeScript, Redux Toolkit, SQLite, API Integration, Feature Flags, User Management, Workout Management
