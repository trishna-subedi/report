\begin{itemize}
    \item \textbf{Front Desk Staff:} Handles member reception, inquiries, membership registration, and fee processing.
    \item \textbf{Trainer Team:} Comprises fitness trainers, personal coaches, and a Zumba instructor who guide members in workouts and exercise techniques.

\section{Literature Review}
This section reviews scholarly literature across six domains relevant to the technologies and methodologies applied during the internship.

\subsection{Cross-Platform Mobile Architectures}
Developing separate native applications for iOS and Android requires maintaining distinct codebases and engineering teams \citep{biorn2020survey}. Cross-platform frameworks address this by allowing a unified codebase to render native UI components on both platforms. React Native uses a declarative, component-driven approach that maps JavaScript components to native widgets, while the Hermes engine and JavaScript Interface (JSI) enable efficient communication between JavaScript and native threads \citep{banks2020learning}. The Expo ecosystem further simplifies development by providing unified build tooling and standard library abstractions.

For navigation, file-based routing frameworks like Expo Router derive screen hierarchies from the filesystem layout, reducing boilerplate and enabling automatic deep-linking.

\subsection{User-Centered Design and Design Systems}
The usability of personal tracking applications depends on interface coherence and user experience design \citep{abras2004, nielsen1994}. In fitness applications, interfaces must provide immediate readability and intuitive interaction patterns.

Modern design systems use centralized design tokens---semantic color palettes, typography scales, spacing units---to maintain visual consistency \citep{frain2022}. Building atomic components (buttons, cards, input fields) from shared tokens ensures visual harmony across screens and supports dynamic theme switching without duplicating layout logic.

\subsection{Client-Side State Management}
As mobile applications grow in complexity, managing state through component prop-drilling creates tight coupling and unnecessary re-renders \citep{banks2020learning}. Redux Toolkit establishes a single source of truth with unidirectional data flow, where state modifications are dispatched through actions and processed by deterministic reducers. Listener middlewares enable asynchronous side-effects (such as local storage synchronization) outside the UI rendering thread.

\subsection{Offline-First Architecture and Local Persistence}
Fitness facilities often have limited connectivity, making constant server round-trips impractical \citep{kleppmann2017}. The offline-first paradigm treats local storage as the primary data source, with network synchronization operating as a background process.

SQLite provides an embedded, ACID-compliant database suitable for mobile devices. Type-safe ORM layers such as Drizzle ORM offer TypeScript schema declarations, compile-time query verification, and structured migration management. For sensitive data such as authentication tokens, hardware-backed secure storage (Apple Keychain, Android KeyStore) provides cryptographic isolation.

\subsection{Backend Architecture and RESTful Services}
RESTful APIs provide structured client-server communication through stateless requests and uniform resource identification \citep{fielding2000}. NestJS offers an enterprise-grade TypeScript framework implementing Dependency Injection and modular controller-service layering for maintainable backend services \citep{martin2008clean}. For semi-structured domain models like fitness tracking, MongoDB's document model represents workout sessions and nested exercise sets as cohesive documents, supporting flexible schema evolution \citep{tilkov2010node}.

\subsection{Token-Based Authentication}
JWT (RFC 7519) provides a stateless mechanism for transmitting verifiable claims between client and server \citep{jones2015jwt}. Security best practices separate credentials into short-lived access tokens and longer-lived refresh tokens. When access tokens expire, client interceptors execute a single refresh request and replay queued network calls, preventing race conditions.

\subsection{Synthesis}
The reviewed literature informed the architectural decisions for Project Alcedo: React Native and Expo Router for the modular frontend, SQLite and Drizzle ORM for offline-first persistence, Redux Toolkit for state management, NestJS for backend services, and JWT for authentication. The practical realization of these concepts is detailed in Chapter~3.
