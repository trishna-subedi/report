## Roles and Responsibilities

My primary role was Frontend Development and UI Implementation,
where I worked on application screens and interface components such
as layouts, buttons, cards, input fields, text, spacing, and
navigation between screens. I focused on implementing the user
interface according to the required design and ensuring a consistent
and functional user experience.

In addition to frontend development, I contributed to basic backend
development and frontend-backend integration. My backend-related
responsibilities included working with User Management, Workout
Management, and Feature Management functionalities. I worked with
user information and profile data, including retrieving and updating
user-related information. I also worked with workout-related
operations such as creating, retrieving, updating, and deleting
workout data and connecting these services with the frontend.

I also worked with feature flags, which allowed application features
to be enabled or disabled through backend configuration. I connected
frontend components with backend services, handled the required data
flow, tested the implemented screens and functionalities, and fixed
errors and bugs identified during development.

Through these responsibilities, I applied the concepts learned during
my B.Sc. CSIT program to a real mobile application and gained
practical experience in frontend development, backend integration,
testing, debugging, and the overall software development process.
